Load it into Chrome

Five simple steps, about two minutes. This installs AgentBridge as an unpacked developer extension.

01

Clone & build the project

Clone the repo, install dependencies and build. This generates the browser-ready files Chrome will load — keep this folder somewhere permanent, Chrome runs the extension directly from it.

terminal 
# get the project
git clone <repository-url> agentbridge
cd agentbridge && npm install

# build the extension
npm run build  # → extension/background.bundle.js
               # → extension/content.bundle.js
               # → extension/sidepanel.bundle.js
💡 Tip — A Desktop or Documents location works well. Avoid Downloads, since browsers sometimes auto-clear it.
02

Open Chrome's extensions page

Open Google Chrome, click the three dots menu (⋮) in the top-right corner beside your profile icon, choose Extensions, then click Manage Extensions — or open a new tab and go directly to the address below.

Troubleshooting & FAQ

Everything you might run into while installing AgentBridge — and a few honest answers about how we built this.

Chrome will disable the extension since it can't find the source. Just repeat Step 4 and point Load unpacked at the new location — nothing else needs reconfiguring.
Unpacked extensions don't auto-update. Pull latest, run npm run build again, then hit the refresh icon on the AgentBridge card in chrome://extensions — or remove and re-load the folder.
